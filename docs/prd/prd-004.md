# PRD — PHASE 4 Reporting & Export

Project: Sistem Manajemen Peternakan Telur
Phase: 4
Estimasi: 1 Minggu

---

# 1. Overview

Phase ini berfokus pada sistem pelaporan operasional peternakan yang dapat menghasilkan laporan otomatis dalam format:

- Excel
- PDF

Laporan dapat diakses hanya oleh role:

- super admin

Sistem harus mendukung laporan:

- harian
- mingguan
- bulanan

serta mendukung scheduled report otomatis.

---

# 2. Goals

Tujuan utama phase ini:

- mempermudah monitoring operasional
- menyediakan laporan siap cetak
- mendukung audit operasional
- membantu analisis produksi
- mempermudah distribusi laporan ke owner/manajemen

---

# 3. Scope

## Included

- Export Excel
- Export PDF
- Scheduled report
- Filter laporan
- Rekap produksi
- Rekap pakan
- Rekap kesehatan ayam
- Rekap populasi kandang

---

## Excluded

- Grafik analytics advanced
- AI prediction
- Financial accounting
- Multi-branch reporting
- Email delivery
- WhatsApp integration

---

# 4. Role & Permission

## Super Admin

Akses penuh:

- melihat seluruh laporan
- export Excel
- export PDF
- generate report manual
- mengatur scheduled report

---

## Worker / Pegawai

Tidak memiliki akses.

---

# 5. MODULE 10 — Laporan Otomatis

---

# 5.1 Dashboard Reporting

Halaman utama reporting.

## Features

### Filter laporan

Filter berdasarkan:

- tanggal
- range tanggal
- kandang
- jenis laporan

### Jenis laporan

- produksi telur
- penggunaan pakan
- kesehatan ayam
- vaksinasi
- populasi kandang

---

## Deliverables

✅ Filter laporan
✅ Rekap data
✅ Preview laporan

---

# 5.2 Export Excel

Sistem dapat mengexport laporan ke format `.xlsx`.

---

## Isi Export

### Produksi telur

- tanggal
- kandang
- jumlah telur baik
- jumlah telur retak
- jumlah telur rusak
- total produksi

### Pakan

- jenis pakan
- stok awal
- penggunaan
- sisa stok

### Kesehatan

- kandang
- jenis penyakit
- jumlah ayam sakit
- tindakan

---

## Rules

- filename otomatis
- format tabel rapi
- mendukung filter aktif
- export mengikuti periode laporan

---

## Naming Convention

```text
laporan-produksi-harian-2026-05-19.xlsx
```

---

## Deliverables

✅ Export Excel
✅ Auto filename
✅ Filter-aware export

---

# 5.4 Scheduled Reports

Sistem dapat membuat laporan otomatis berdasarkan periode tertentu.

---

## Schedule Types

### Mingguan

Generate setiap minggu.

### Bulanan

Generate setiap bulan.

## Features

- tersimpan di database
- histori report
- download ulang report lama

## Rules

- scheduled job berjalan otomatis
- report disimpan sebagai file/url
- report memiliki timestamp

---

## Deliverables

✅ Scheduled reports
✅ Report history

# 7. Non Functional Requirements

---

## Performance

- export maksimal < 10 detik
- support minimal 10.000 rows

---

## Security

- hanya super admin dapat akses
- validasi authorization
- signed download URL

---

## Reliability

- scheduled report retry jika gagal
- file export tidak corrupt

# Objective

Membangun sistem operasional inti peternakan ayam petelur yang dapat digunakan untuk aktivitas harian secara nyata.

Fase ini merupakan fondasi utama aplikasi dan harus mampu:

- mencatat produksi telur
- mengelola kandang
- mengelola stok pakan
- mencatat kesehatan ayam
- menampilkan dashboard operasional

Target utama:

> aplikasi sudah usable untuk operasional harian kandang.

---

# Success Criteria

## Operational Success

- pekerja dapat input produksi harian dengan cepat
- owner dapat melihat kondisi kandang secara realtime
- stok pakan dapat dipantau
- mortalitas dapat dicatat
- data operasional tersimpan dengan baik

---

## Technical Success

- mobile responsive
- form submission cepat
- validasi berjalan
- role protection berjalan
- dashboard realtime sederhana berjalan

---

# User Roles

## Owner

Memiliki akses penuh:

- dashboard
- kandang
- produksi
- pakan
- kesehatan ayam

---

## Worker

Memiliki akses:

- input produksi

- pengaturan sistem
- laporan finansial

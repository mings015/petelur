- manajemen pegawai
- tugas harian operasional

- terstruktur

# Success Criteria

## Operational Success

- owner dapat mengelola pegawai
- pegawai memiliki checklist tugas harian
- akses data sensitif terlindungi
- worker hanya melihat fitur sesuai tugasnya

---

## Technical Success

- middleware permission berjalan
- role-based UI berjalan
- audit log berjalan
- unauthorized access dicegah
- mobile responsive

# MODULE 2 — Multi User & Role

# Objective

Mengatur hak akses sistem berdasarkan role user.

---

# Roles

# Owner

Memiliki:

- full access

---

# Worker

Memiliki akses:

- input operasional
- checklist tugas
- produksi telur
- pakan
- kesehatan ayam

Tidak memiliki akses:

- finance
- laporan keuangan
- pengaturan sistem
- data sensitif

---

# Permission Rules

# Owner Access

Owner dapat:

- create/update/delete seluruh data
- melihat seluruh dashboard
- mengakses finance
- mengelola pegawai
- melihat analytics

---

# Worker Access

Worker hanya dapat:

- input data operasional
- melihat halaman operasional
- checklist tugas

Worker tidak dapat:

- menghapus data sensitif
- melihat profit/loss
- melihat pengeluaran
- mengakses role management

---

# Functional Requirements

# Role-Based Sidebar

Sidebar harus berubah berdasarkan role.

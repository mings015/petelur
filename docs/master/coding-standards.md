# Coding Standards

## Egg Farm Management Dashboard

# General Principles

## 1. Readability First

Kode harus:

- mudah dibaca
- mudah dipahami
- mudah di-maintain

Hindari:

- overengineering
- abstraction berlebihan
- magic code

---

# Language Rules

## TypeScript Strict Mode

Wajib:

- strict typing
- no implicit any
- explicit types untuk object penting

---

# Naming Conventions
